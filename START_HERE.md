## ❓ FAQ

**Q: Do I need to install anything else?**
A: No! All dependencies are in `node_modules/`. Just run `npm run push`.

**Q: What if I want to customize it first?**
A: Run `npm run dev` and edit files in `app/components/`. Changes appear instantly.

**Q: Can I use a custom domain (tsvetkov.site)?**
A: Yes! After deploying to Vercel, you can add your custom domain in settings.

**Q: How do I make changes after it's live?**
A: Edit files, test with `npm run dev`, push to GitHub with `npm run push`, and Vercel auto-deploys.

**Q: What if push fails?**
A: See FINAL_STEPS.md "Troubleshooting" section. Usually it's token-related.
